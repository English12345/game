# Folder Video Facecam / Rekaman Orang Main

Taruh video rekaman kamu (atau siapa pun yang "kelihatan main") di sini dengan nama **angka urut**:

```
1.mp4
2.mp4
3.mp4
4.mp4
...
```

Aturan:
- Format harus `.mp4` (disarankan H.264, agar kompatibel di semua browser)
- Nama file **hanya angka**, dimulai dari `1`
- Sebaiknya video berbentuk persegi (1:1) atau potret dekat wajah, karena akan ditampilkan bulat kecil di pojok kanan atas
- Disarankan durasi tiap klip 5–30 detik supaya perpindahan antar klip terasa natural

Cara kerja saat live:
- Video-video ini **otomatis di-mute** (supaya tidak bentrok dengan voice over & efek suara game)
- Semua file diacak urutannya, diputar satu per satu, lalu diacak ulang — loop selamanya
- Tampil sebagai lingkaran kecil dengan cincin gradient berputar di HUD atas

Tips kualitas: gunakan video dengan pencahayaan bagus dan ekspresi/reaksi yang related dengan gameplay (kaget, senang, fokus) supaya suasana "orang lagi main" terasa hidup meskipun sebenarnya loop.
